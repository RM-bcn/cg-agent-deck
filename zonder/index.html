De grenzen die je zelf zet

  • Budget: Console workspace-budget (de harde muur) + max runs per dag.
  • Tijd: 10 minuten per run, daarna SIGTERM.
  • Toegang: GitHub alleen op 2–3 repo's; geen main.
  • Lock: één run tegelijk.

De lus, letterlijk

*/15 * * * *  node src/collect.mjs
*/15 * * * *  node src/run-if-needed.mjs

# run-if-needed:
#   open p0/p1?  › opencode run --auto
#   geen lock?   › start
#   klaar        › PR + verslag + state

Wat je houdt

  • dedupe: één incident per oorzaak
  • automatisch sluiten bij herstel
  • de vraag met knoppen
  • audit: wie, wanneer, welk bewijs

Wat je inlevert

  • geen organogram of hire-approvals
  • geen kosten per agent (alleen totaal)
  • geen run-history-UI — wel events.ndjson

Wanneer Paperclip wél

  • zodra de CMO erbij komt
  • zodra je per agent wilt budgetteren
  • zodra je een hire wilt goedkeuren
